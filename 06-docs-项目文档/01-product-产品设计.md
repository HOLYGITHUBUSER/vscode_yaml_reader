# 产品设计 — YAML Reader

## 定位

同一编辑器界面阅读 / 轻量编辑 YAML：**左结构树、右可编辑源码**。  
不是 Language Server，也不用侧栏大纲当主界面。

## 布局

| 模式 | 说明 |
|------|------|
| **分栏（默认）** | 左树 + 右源码 |
| 树形 | 仅结构 |
| 源码 | 仅编辑 |

状态栏循环切换三种布局。

## 核心能力

- 树：展开折叠、搜索、类型色、路径、点选定位源码
- 源码：编辑 debounce 写回文档
- 多文档 `---`、maxNodes 截断
